# 稳定编号与手动导入对账


For every intake, reconcile the current Vault before assigning a number, then apply numbering after Formal Save and registration. This is an agent workflow requirement: the current `intake.py` helper does not allocate numbers or repair links after renames.

- Scan actual PDF files, personal reading homepages, AI-note associations, the bibliography and `论文入库登记.json`; do not rely only on the registry or a remembered last number. Include manually imported PDFs and notes. Inspect filename prefixes such as `001 `, `001_`, `001-`, and explicit `paper_number` properties. A year, DOI, arXiv ID or hash is not a paper number.
- One paper has one stable number. Match manual files by explicit PDF links, PDF hash, verified DOI or an existing stable association; titles alone are only candidates. Reuse the number when adding notes or another source version to the same work. Unlinked notes with uncertain identity must not be silently paired with a PDF.
- Preserve established numbers and gaps. For an unnumbered paper, use the maximum number actually reserved anywhere in the Vault plus one, padded to at least three digits (`001`, `002`, …). Never use file count plus one or recycle a deleted paper's number. Recheck the files immediately before applying changes. Conflicting numbers for one paper, or one number assigned to distinct papers, require reporting the concrete conflict before changing those affected files.
- Reconcile confidently identified, manually imported unnumbered papers before assigning the new intake's number. Keep their personal prose and existing associations. If several old papers have no recoverable intake order, use an explicit order already recorded in the bibliography; otherwise use a reproducible filename order and disclose that this is a backfill order, not a verified historical reading order. Reserve visible existing numbers even when their associations remain unresolved.
- Use matching visible prefixes for the personal homepage and PDF, e.g. `003 VizCrit：视觉设计反馈策略.md` and `003 VizCrit：视觉设计反馈策略.pdf`. Retain a disambiguating version/hash suffix when needed. Store integer `paper_number` on the personal homepage and its registry entry. Keep `reference_id` unchanged. If an established numbered filename already uses a different separator, preserve it.
- The user explicitly requires the same visible prefix on the AI paper folder AND its Markdown filename, in addition to the PDF and personal homepage. Example: `003 论文名称/003 论文名称.zh-CN.md`, with the existing domain folder retained. An AI version reuses the paper number; preserve its language/version suffix. Avoid double-prefixing already numbered names. Perform this as a backed-up post-save migration, outside an active admission/save transaction. Keep AI Markdown bytes and paper-local image filenames/content unchanged; moving the intact folder preserves relative image links. Update registry paths and all incoming links. For a Formal Save archive, also update only affected filename/path metadata in `.deeppapernote.json` (including root/source `note_stem` and language-note `filename`); retain identity, provenance, source hashes and note hashes. Verify that each sidecar record resolves to the renamed file with the original hash. If the installed archive schema cannot be safely reconciled, report the specific blocker rather than silently skipping AI numbering or breaking the archive.
- Before renaming a PDF, homepage, AI note or AI folder, prepare an old-to-new path map and check destination collisions. Prefer Obsidian's link-aware rename when available. Otherwise update affected wikilinks, embeds, Markdown links, `pdf`/`source_note` properties and registry paths explicitly; do not perform blind global title replacement. Do not rewrite protected formally saved AI files: if one contains a link to an old path, keep the target path intact and use properties/display labels for numbering instead, explaining the exception.
- Run `intake.py refresh` after reconciliation and verify PDF links, homepage-to-AI links, registry paths, unique number-to-paper associations and unchanged saved AI-note hashes. Ensure numbers remain visible in the bibliography through the numbered homepage label. Report the assigned/reused number and any manual imports reconciled; do not claim that the background PDF watcher independently implements these numbering rules.
